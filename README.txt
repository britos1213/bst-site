RECURSOS

- Catálogo com busca e filtro por categoria
- Página individual de produto
- Carrinho usando localStorage
- Envio da lista do carrinho pelo WhatsApp
- Produtos sem preço exibem "Preço sob consulta"
- Área do cliente apontando para app.bst.inf.br

CADASTRO DE PRODUTOS

IMAGENS
